# meu portfólio interativo

Portfólio pessoal em formato de parque jurássico em pixel art. Explore o mapa e interaja com as baias para conhecer projetos, currículo e outras informações.

## Tecnologias

- React
- TypeScript
- Phaser
- Vite

## Como executar

Pré-requisitos: Node.js e npm.

```bash
npm install
npm run dev
```

## Outros comandos

```bash
npm run typecheck
npm run build
npm run preview
```
